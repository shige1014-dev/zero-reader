📖简介

韩国 2024 年总和生育率 0.72 — 全球最低, 远低于人口替代率 2.1. 同时, 65 岁以上人口占比已达 19%, 2030 年破 25%, 2050 年 40%. 这是日本 1990 年代以来全球最快的老龄化曲线.

▸ 核心

未来 25 年韩国必须从 移民 / 自动化 / 生育激励 三选一. 任何单一方案都不够. 这是韩国 GLP-1 / 机器人 / 养老科技 三大长期主题的根本驱动力.

▸ Soft Power · 文化软实力

K-Pop / K-Drama 全球账

📖简介

韩国文化输出 (Hallyu, 韩流) 2024 年全球收入约 $130 亿. 其中 K-Pop $90 亿 / K-Drama $25 亿 / K-Beauty $15 亿. Netflix 非英语剧 60% 是韩剧 / 西语剧, 韩剧占 30%. BTS / Squid Game / Parasite 让韩国成为继日漫之后的第二个 "文化超级出口国".

文化软实力不只是 entertainment 收入 — 它是 国家品牌 + 旅游 + 化妆品 + 食品出口 的乘数放大器. 韩流 GDP 贡献 0.4% (约 $80 亿), 但带动效应 2-3 倍.

▸ Geopolitics · 中美夹缝

韩国 · 安全靠美 经济靠中

📖简介

韩国是冷战后唯一同时高度依赖 美国 (安全 + 美军 + 半导体技术) 和 中国 (出口 + 供应链) 的大经济体. 韩对中出口占总出口 20% (vs 美 18%, 日 7%, 越 9%). Trump 2.0 + 中美脱钩, 这个平衡正在被强行打破.

▸ 核心

韩国未来 5 年面临 三选一: (A) 全面美国阵营 (CHIPS Act + IRA + Aukus) / (B) 中间走平衡 / (C) 中国阵营 (经济换市场). 大概率走 A + B, 但代价是中国市场永久流失 20-30%.

023 大冲击 (Trump 2.0)

①CHIPS Act 配套要求

美国要求 TSMC + Samsung + SK Hynix 在美建厂. 三星已投 $500 亿建得州工厂, SK Hynix 在印第安纳州 HBM 厂. 对中国市场影响: 美国限制对中销售先进芯片, 三星 / SK 中国市场被压缩.

②IRA + EV 关税

韩国 EV / 电池厂在美投资 +$500 亿 (LG新能源 / SK On / 三星 SDI). 但 IRA 2025 起部分修订, 中国成分电池被排除. 影响: 韩国电池公司必须重组供应链.

③普遍关税威胁

Trump 2.0 提 10-20% 普遍关税 + 60% 对中国. 韩国对美顺差 $44B (2024), 高敏感商品: 汽车 / 半导体 / 电池. 预期: 韩美 FTA 重谈, 部分产品关税豁免.

03韩国的对冲

  1. 东南亚 + 印度 +欧洲扩张: 不再依赖单一中国市场
  2. 国防自立 + 出口: K-Defense 是经济 + 安全双重答案
  3. 核电 + 能源自主: 减少对中国稀土 / 太阳能依赖
  4. 文化 + 旅游: 软实力作为非对抗性外交工具

▸ Glossary · 术语注解

看懂这一刊的关键词

📖本刊术语

本期周刊出现的所有专业术语 + 韩国本土词汇 + 投资行话, 一站式查阅. 按主题归类.

01半导体 + AI

HBM (High Bandwidth Memory)
高带宽内存, NVDA H100/B200 GPU 必备. 韩国 SK Hynix 主导, 三星 + 美光跟随.
HBM3E / HBM4
HBM 代际, 数字越大越新. HBM3E 是 2024-2025 主流 (8 层 / 12 层), HBM4 是 2026 量产新一代 (16 层).
2nm GAA
2 纳米 Gate-All-Around 工艺, 半导体最先进制程. 三星 / TSMC 2026 量产.
NVDA Rubin
NVIDIA 下一代 GPU 平台 (Blackwell 之后), 2026 量产. HBM4 是核心配套.
Foundry
代工厂. 三星 / TSMC 是主要 foundry, 为 NVDA / AMD / Apple / Qualcomm 代工.

02金融 + 估值

PE (Price/Earnings)
市盈率 = 股价 / 每股收益. 简单估值指标. KOSPI 平均 PE 11, S&P500 PE 22.
PB (Price/Book)
市净率 = 股价 / 每股净资产. 重资产行业 (银行 / 制造) 常用.
ROE / ROIC
ROE = 净利润 / 净资产. ROIC = 营业利润 / 投资资本. Value-Up 要求 ROE > WACC.
Backlog
未交付订单. 造船 / 国防业关键, 反映未来 3-5 年收入.
SOTP (Sum of the Parts)
分类估值法. 财阀股因业务多元, 常用 SOTP 而非单一 PE.

03韩国本土

财阀 (재벌, Chaebol)
韩国大型家族企业集团. 三星 / SK / Hyundai / LG / Lotte 五大占 GDP 40%+.
Value-Up Program
韩国政府 2024-2025 推出的财阀重估改革, 强制分红 + 回购 + 透明化. 目标 KOSPI PE 从 11 → 18.
Korea Discount
韩股长期被市场低估的现象, PE 仅美股一半. 财阀治理 + 朝韩风险是主因.
Hallyu (한류, 韩流)
韩国文化输出现象, 含 K-Pop / K-Drama / K-Beauty / K-Food.
KOSPI
韩国综合股价指数. 类似上证 / 日经.
KOSDAQ
韩国创业板, 类似纳斯达克. 中小成长股集中.

04国防 + 地缘

K-Defense
韩国国防工业出口品牌. K2 坦克 / K9 自行炮 / FA-50 战机 / 天弓-II 防空.
CHIPS Act
美国 2022 通过, 给在美建半导体厂的公司 $520 亿补贴.
IRA (Inflation Reduction Act)
美国 2022 通过, 对 EV / 电池 / 可再生能源补贴. 韩国电池公司受益.
THAAD (萨德)
美国在韩部署的反导系统. 2016 部署引发中国限韩令.
Aukus / Chip4
美国主导的两个对中科技 / 安全联盟, 韩国是关键参与者.

05事件 + 周期

CII 评级
国际海事组织 (IMO) 船舶碳强度评级, 2024 起强制. 老船面临停航, 拉动双燃料船需求.
FOMC
美国联邦公开市场委员会, 每年 8 次决定利率. 影响 KRW 汇率 + KOSPI 流动性.
Sharpe Ratio
风险调整收益 = (回报 - 无风险利率) / 标准差. > 1 优秀, > 2 卓越.
最大回撤 (Max Drawdown)
从峰值到谷底的最大跌幅. 评估策略下行风险.
Black Swan
低概率高影响事件. 韩国主线最大单一 Black Swan = 朝鲜冲突.
