---
concept: 行业 vs 公司 alpha
question: 你赚的是行业风口的钱，还是公司本身的钱？
definition: 行业 alpha = 整个赛道因结构红利产生的超额；公司 alpha = 同行业内由经营能力 / 战略选择产生的超额。
mechanism: 行业 alpha 来自需求曲线 + 监管 + 资本周期；公司 alpha 来自管理层 / 护城河 / 资本配置。混淆两者会误判可持续性。
example: 2020-2021 SaaS 普涨，多数公司 alpha 是行业风口；2022 同行业内 NOW / CRWD 跑赢，才显公司 alpha。
misconception: 把牛市里的成功归因到公司能力；不做行业归因就放大对管理层的信任。
practice: 做归因分解 — 总收益 = 市场 beta + 行业 alpha + 公司 alpha + 残差，季度复盘。
reviewPrompt: 这只票最近 12 个月超额收益里，多少来自行业？多少来自公司？
