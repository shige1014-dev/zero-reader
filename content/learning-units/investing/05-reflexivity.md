concept: 反身性 (Soros)
question: 价格本身能不能改变它要反映的基本面？
definition: 反身性 — 市场参与者认知影响价格，价格又反过来改变基本面，形成自我强化或自我毁灭的循环。
mechanism: 上涨 → 抵押品价值升 → 信贷扩张 → 投资增长 → 利润提升 → 进一步上涨；反向亦成立(死亡螺旋)。
example: 2007 美国房贷 — 房价涨推动 MBS 评级稳定 → 信贷扩张 → 房价继续涨；2008 反向：违约 → 评级降 → 强制平仓 → 进一步违约。
misconception: 把市场当被动反映器；忽视价格反作用于基本面的机制。
practice: 找一个反身性循环正在运行的资产 (信贷 / 加密 / 商品)，画双向反馈图。
